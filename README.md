# Terraform Installer

One-liner shell script to install the latest **Terraform** on Ubuntu/WSL using HashiCorp's official APT repository.

## Prerequisites

- Ubuntu 20.04+ (or WSL2)
- `sudo` access
- Internet connection

## Usage

```bash
# Clone the repo
git clone https://github.com/<your-username>/terraform-installer.git
cd terraform-installer

# Run the installer
sudo bash install.sh
